# A999-Activator-Patch
A simple script to patch the A999 Activator in order to continue to downgrade iPhone 6s and 6s+

## How to use:
1 - Download A999 V1.1.0 (NOT V1.1.1 or later) https://github.com/alex-free/a999activator/releases/tag/v1.1.0

2 - Download the latest release of A999 Activator Patch

3 - Open up Terminal and drag the A999 Activator Patch into the Terminal window and press Return

4 - Once the script launches, choose the A999 Activator executable by pressing Return and then choosing a999 from the Finder.

5 - Using the arrow keys, choose Begin Patching. You may need to enter your account password.

6 - Once patching is complete, you can either exit the script or start the A999 activator.

7 - If you ever want to revert patches, launch the script again and choose Revert Patches.
